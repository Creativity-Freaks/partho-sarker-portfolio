# Partho Sarker Dhrubo Portfolio

A modern personal portfolio for Partho Sarker Dhrubo, focused on bioinformatics, molecular docking, agricultural innovation, and field/lab research work.

## Project Summary

This project is a single-page portfolio built with React, TanStack Router/Start, Vite, TypeScript, and Tailwind CSS. It presents research highlights, lab and field photography, leadership roles, publications or poster work, and direct contact links.

## Features

- Hero section with profile and career highlights
- Research and project showcase
- Lab and field image gallery
- Leadership and skill sections
- Contact section with email, phone, Facebook, and LinkedIn links
- Responsive layout with animated visuals
- SEO metadata via route head configuration

## Tech Stack

- React 19
- TypeScript
- Vite
- TanStack Router / TanStack Start patterns
- Tailwind CSS 4
- Motion
- Radix UI components

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
